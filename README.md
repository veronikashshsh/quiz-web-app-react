Quiz Web App

A modern React quiz application that lets users test their knowledge across multiple categories with an intuitive and responsive interface.

Live Demo
🌍 Website: https://quiz-web-app-react.vercel.app/
💻 Repository: https://github.com/veronikashshsh/quiz-web-app-react

Features

1. Browse quiz categories
2. Interactive multiple-choice questions
3. Instant answer validation
4. Final score screen
5. Progress indicator
6. Responsive design
7. Modern and clean UI
8. Firebase Authentication

Tech Stack

- Frontend: React, Typescript
- Styling: Tailwind CSS
- Tooling: Vite, ESLint

Installation

git clone https://github.com/veronikashshsh/quiz-web-app-react.git

cd quiz-web-app-react

npm install

npm run dev
